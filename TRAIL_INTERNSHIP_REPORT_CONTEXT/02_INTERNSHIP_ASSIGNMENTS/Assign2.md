# Assignment 02: Platform Architecture — Spotify

## 1. Platform - Spotify
For this assignment, I selected Spotify. Spotify is a music and audio streaming platform. It provides music, podcasts and audiobooks through its website and mobile and desktop applications. Users can search for content, create playlists, follow artists and get recommendations based on their listening habits.

---

## 2. Pre Defined Objective of Spotify
The basic objective of Spotify is to make audio content easy to discover and listen to. It connects listeners with artists and other creators and tries to give users a personalised listening experience. 

Spotify wants a user to find something they like, listen to it easily, and keep discovering new content. Personalisation is an important part of this objective. Spotify says that recommendations use different signals from user behaviour, such as listening, skipping, saving songs and interacting with artists. Its newer strategy is also moving towards more interactive and AI-based personalisation.

---

## 3. Five Main System Components

### 1. User Interface (Website / App)
This is the part the user directly sees. It includes the home page, search, playlists, albums, artist pages, player and account section. The same Spotify account can be used across different devices such as phones, computers, TVs, speakers and cars.

### 2. User Account and Database
Spotify needs to store user information such as accounts, playlists, saved content, preferences and other activity. This helps the system remember the user's library and provide a personalised experience. Spotify's privacy information also explains that its services involve personalisation and the infrastructure needed to provide the service.

### 3. Music and Content Streaming System
This component delivers songs, podcasts and other audio/video content to the user's device. The system has to handle a very large amount of content and deliver it smoothly when a user presses play. Spotify currently describes its service as providing access to over 100 million tracks, millions of podcast titles and audiobooks in selected markets.

### 4. Search and Recommendation System
Search helps users find a particular song, artist, album or podcast. The recommendation system is used for things like personalised playlists and discovery. Spotify has publicly explained that it combines algorithmic systems with human editorial expertise to recommend content.

### 5. Payment, Subscription and Advertising System
Spotify works with a free/ad-supported model as well as Premium subscriptions. The system therefore needs to manage subscriptions, payments, advertisements and the different features available to different users. Premium features in India include ad-free listening, offline listening and more control over playback.
